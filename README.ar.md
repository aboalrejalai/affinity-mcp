# Affinity MCP: مهارة وكلاء الذكاء الاصطناعي لبرنامج Affinity by Canva

**خلّ Claude وCursor وCodex يعدّلون صورك ويصممون ويرتبون مستنداتك داخل Affinity by Canva، عن طريق خادم MCP المدمج في البرنامج وواجهة JavaScript الخاصة به.**

[English](README.md) · [العربية](README.ar.md)

---

**Affinity by Canva** هو البرنامج المجاني اللي خلف Affinity Photo وDesigner وPublisher، وفيه **خادم MCP محلي**. أداته `execute_script` تشغّل JavaScript داخل البرنامج نفسه، مع وصول كامل للـ SDK:
- 20 وحدة أصلية و372 أمر.
- الفيكتور والبكسل والـ Layout والخطوط والفلاتر والتصدير.
- وأوامر Canva AI.

الخادم يعطي الوكيل القوة، لكن ما يعلّمه كيف يستخدمها. هذا المشروع يضيف هالخبرة: **مهارة (Skill) مجرّبة** تعلّم الوكيل يستخدم هالقوة بشكل صحيح وآمن، وهي متوفرة كإضافة لـ **Claude Code وCursor وCodex**.

> «قص صورة الحفل مربعة حولي، شيل اليد اللي على كتفي، بلّر اللي ورايا، ووسّط وجهي عشان LinkedIn.»
>
> الوكيل اللي عنده هالمهارة يسوي هذا كله داخل Affinity: يتحقق من كل خطوة بصرياً، ويسلّمك JPEG جاهز، وملف `.af` بطبقاته يقدر أي مصمم يكمل عليه.

## وش يقدر يسوي الوكيل؟

| المجال | أمثلة |
|---|---|
| **تعديل الصور** | قص، تغيير حجم، إزالة عناصر، فصل الشخص، بلور الخلفية، توسيع الصورة، 30 فلتر، وتعديلات لونية حية (Levels وCurves وHSL وغيرها) |
| **الفيكتور** | أشكال، نجوم، أسهم، رموز QR، مسارات، دمج أشكال، تدرجات، حدود، ظلال، وتتبع الصور |
| **النصوص والـ Layout** | نص فني ونص إطار، نص على مسار، **عربي صحيح من اليمين لليسار**، جداول، مستندات متعددة الصفحات، Artboards |
| **Canva AI** | توليد صور، تعديل توليدي، إزالة الخلفية، تحديد الشخص، خريطة عمق، تلوين |
| **التصدير** | 62 صيغة: PNG وJPEG وWebP وSVG وPDF وPDF للمطابع، وغيرها |

## البداية السريعة

**1. فعّل الخادم في Affinity:** من **Settings ← Model Context Protocol ← Enable Affinity MCP**، واختر الصلاحيات، وبعدها **سكّر البرنامج وافتحه من جديد**.

**2. ثبّت الإضافة:**

Claude Code:

```bash
claude plugin marketplace add aboalrejalai/affinity-mcp
```

```bash
claude plugin install affinity@affinity-mcp
```

Codex:

```bash
codex plugin marketplace add aboalrejalai/affinity-mcp
```

```bash
codex plugin add affinity@affinity-mcp
```

Cursor: من **Settings ← Plugins** الصق رابط المستودع `https://github.com/aboalrejalai/affinity-mcp`.

**3. اطلب:** افتح مستند في Affinity وكلّم الوكيل. للتأكد من الاتصال اسأله: «تشوف خادم Affinity MCP؟ وش المستندات المفتوحة؟»

## أمثلة طلبات

- «شيل خلفية الصورة المفتوحة وصدّرها PNG شفاف على سطح المكتب.»
- «خل صورة القروب هذي صورة بروفايل مربعة، وجهي في النص، والخلفية مبلورة.»
- «صمم بوست انستقرام 1080×1080، بتدرج أخضر وبطاقة بيضاء وعنوان «عرض خاص».»
- «سوّ فلاير A5 فيه QR لموقعي، وصدّره PDF للطباعة.»

## الحدود

هذي حدود من الـ SDK حق Affinity نفسه، مو من المشروع:
- السكربت ما يقدر يختار نموذج الذكاء الاصطناعي (Nano Banana وGPT Image وغيرها)، فهذا يتحدد من واجهة البرنامج.
- أدوات Expand وUpscale وتوليد الفيكتور والـ 3D ما لها أوامر سكربت. للتوسيع، المهارة فيها بديل مجرّب.
- ما فيه حافظة (نسخ ولصق) ولا ضغط على الأزرار، والملفات محصورة في سطح المكتب.

## الأمان

المهارة تلزم الوكيل إنه:
- **يشتغل على نسخة** من ملفك.
- **يستأذن قبل ما يصرف رصيد Canva AI**.
- ما يحفظ ولا يسكّر ولا يكتب فوق أي ملف ما سوّاه هو.
- يتحقق من كل تغيير بلقطة.

وصلاحيات Affinity نفسها تبقى مطبّقة دائماً. التفاصيل في [SECURITY.md](SECURITY.md).
